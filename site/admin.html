用 Google 帳號登入營運管理。

這個登入只用在這一頁，你在聊天室裡仍然是匿名的。

這個 Google 帳號還不是管理員。把下面這個 ID 加為管理員：

  1. 打開 Firebase 主控台的 Realtime Database。
  2. 在最上層按「＋」，依序新增 ops → admins → 這個 ID，值填 true。
  3. 回來重新整理這一頁。

這個 ID 屬於你的 Google 帳號，只要加一次。之後在任何瀏覽器或手機用同一個 Google 帳號登入，都是管理員。

停權名單

被停權的裝置不能開房、加入或發言，但能離開房間。換裝置或清除瀏覽器資料就能避開，這是免註冊的限制。

推播金鑰

推播服務：檢查中…

  1. 按「產生金鑰」，複製出現的整段文字。金鑰只在你的瀏覽器裡產生，不會傳到任何地方。
  2. 到 GitHub 的 samhung7/anon-chat → Settings → Secrets → Actions，新增 secret，名稱 VAPID_KEY，值貼上剛才那段。
  3. 到 Actions → Deploy photo service 按「Run workflow」。完成後重新整理這一頁，這裡會顯示「已啟用」。

金鑰設好後不要再換：換了之後，每個人的推播訂閱都要等他們重新進房才會更新。
